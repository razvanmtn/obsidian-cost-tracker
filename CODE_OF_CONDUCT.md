# Code of Conduct

Be respectful. Harassment, hate speech, and personal attacks are not allowed in issues, pull requests, or discussions.

If something crosses that line, contact the maintainer through GitHub or open a private [security advisory](https://github.com/razvanmtn/obsidian-cost-tracker/security/advisories/new) when the report should stay confidential.

Maintainers may hide, lock, or close contributions that break this policy.
