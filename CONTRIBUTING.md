# Contributing

Bug reports, feature ideas, and pull requests are welcome.

## Development

```bash
npm install
npm run dev
```

Open this folder as an Obsidian vault, enable **Cost Tracker**, and reload the plugin after changes if needed.

```bash
npm run build
```

Please keep the production build passing before you open a pull request.

## Pull requests

- Prefer small, focused changes
- Match the existing TypeScript style (tabs, strict types)
- Do not commit `main.js`, `node_modules`, or vault workspace files
- Explain the why in the PR description

## Releases

Maintainers cut releases by tagging a version. See the [README](README.md#release) for the exact steps.
